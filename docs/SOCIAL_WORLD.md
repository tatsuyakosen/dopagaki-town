# 実在都市で集まり、遊び方を選べる共有世界

## 方向

OZのように、同じ世界で人が集まり、交流し、目的や遊びを選べる自由度を長期目標とする。
最初の利用者は、離れた場所から短時間一緒に遊びたい友人2〜4人。実都市を共通の話題と遊び場にする。
予約・決済など現実の取引は初期の主機能にしない。街の形状や出典は実データを守り、ゲーム用の障害物・目標・演出は区別する。

世界の広さだけで完成としない。選べる道、別行動と合流、相手への働きかけ、遊びを始める選択肢を増やす。
全国や大規模同時接続への拡大は、梅田の小さな範囲で入場・移動・交流・遊びの一連の体験を確認した後に行う。

## 今回の到達点

- 地図から構築した実都市の街歩きで、最大4人の招待ルームを作成・参加できる。
- 参加者の色・表示名、相手のアバター、ルーム内の短いテキストチャットを表示する。
- 参加時の開始街区IDをサーバーが固定する。別ステージIDでの参加は拒否し、別ルームの状態・チャットを送らない。
- 1km内は各端末が周辺街区を読み込む。相手がいる街区を自分が未読込なら、そのアバターは表示しない。
- 勝敗・制限時間なし。一人でも歩け、ルームを退出しても街歩きを続けられる。
- 一時的な通信断では30秒間同じ参加枠を保持し、最大3回自動再接続する。ページ再読込時は参加者IDを再利用できるが、歩行位置はクライアントの安全な開始地点からになる。
- 名前・チャットをHTMLとして解釈しない。チャット入力中に移動キーが残らないようにする。

実都市の協力的な位置共有であり、対戦判定との統合ではない。
サーバーは有限座標・範囲・入力順序を検査するが、移動速度や地形・壁の衝突を再計算しない。参加者は互いを押さず、通り抜ける。
周辺街区のLODは各端末の品質設定で異なり得る。競技用の完全な形状・経路グラフの一致保証には使わない。

## 実行と共有

Node.jsとnpmだけで動く。

```sh
npm ci --ignore-scripts
npm run dev:client
```

表示URLの `/map.html` から入場し、「友達を招待する」→「招待リンクをコピー」。相手はリンクを開き、表示名を決めてルームに参加する。
招待リンクは自分で相手に渡す。アプリからメール等を自動送信しない。
招待先も同じサーバーに接続する必要があり、localhostのリンクを別のPCへ渡しても接続できない。
別PCで試す場合はアクセス可能なホスト名・ネットワーク構成が必要。インターネット向けクラウド公開はこの変更に含まない。
`npm run build` → `npm run preview:client` でも同じ共有機能が動く。静的ファイルだけを配信してもWebSocketや構築APIは動かない。
既存の `npm start` は架空都市の鬼ごっこ用で、実都市の共有APIは提供しない。

招待情報はURLのfragmentに置き、個人の再接続トークンを招待URLに含めない。
リンクを持つ人が参加できる方式であり、リンクの受信者を本人確認する機能はない。
ルーム内の参加者がいなくなってから一定時間でルームが消え、サーバー再起動では全ルーム・チャットが消える。
街区データ自体の24時間キャッシュ期限が切れた場合も、地図から構築し直す必要がある。

## 負荷と保存範囲

| 対象 | 上限・動作 |
| --- | --- |
| 1ルーム | 4人。通信断の参加枠は30秒保持 |
| 1プロセス | 32ルーム、未参加接続を含む128接続 |
| 位置共有 | 送信・スナップショットとも10Hz。ブラウザは相手の位置を補間 |
| 描画 | 自分以外は最大3アバター。影は追加せず、未読込街区・切断した相手は非表示 |
| 通信入力 | 2KiB/メッセージ、30メッセージ/秒/接続、同一オリジンのブラウザ接続 |
| 接続監視 | 未参加は10秒で切断。15秒ごとのping/pong。送信滞留64KiB超は切断 |
| チャット | 140文字、1人1.5秒に1回、直近24件。位置スナップショットのたびに履歴を再送しない |
| 空ルーム | 最終利用から10分で破棄。永続DB・ログ出力なし |
| 端末保存 | タブのsessionStorageへルーム別の再接続トークン。退出時に削除 |
| 都市構築 | 既存の単一ワーカーとキャッシュを共用。構築待ちを取得失敗の回数へ加算しない |

大規模公開用の利用者認証・通報・ブロック・運営管理・水平分散は未実装。現段階は開発環境の招待ルーム。
実機の負荷・ネットワーク遅延での見え方を確認するまで、快適さや同時接続性能を保証しない。

## 次の段階と受入条件

1. **集まる・動く・交流する**：2人の実ブラウザで10分以上、別行動・合流・チャット・切断復帰を確認。標準30FPS/軽量20FPSを測る。
2. **遊び方を選ぶ**：自由な街歩きから1種類の短い遊びを任意で開始し、終わったら同じ街へ戻る。実都市の対戦ならサーバー衝突・経路を先に統合する。
3. **AIが遊びを組む**：人数、希望、地形、進行状況を見て目標とヒントを提案する。目的地点の到達可能性、時間、公平性は通常コードで検査する。無効な案は採用しない。
4. **体験を比較する**：固定ルールとAI進行で、完走、詰まり、もう一度遊ぶ選択を比べる。AIなしを実AIとして表示しない。

AIの応答待ちで移動・描画を停止しない。介入は短い理由とともに見せ、実行履歴・処理時間・失敗は秘密情報を含まない形で確認できる設計を目指す。
今の共有街歩きには、Bot、音声通話、アバター編集、AI進行役、共有ロビー、ユーザーによる自由建築はまだ接続されていない。
